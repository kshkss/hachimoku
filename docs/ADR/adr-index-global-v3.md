# ADR Index: システム全体概要・プロダクトアーキテクチャ設計 (hachimoku)

このドキュメントは、家計簿アプリ **hachimoku** のシステム全体概要、ユーザー体験、運用リソース、および開発構成に関する主要なアーキテクチャ上の決定事項（ADR）をまとめたインデックスです。
アプリケーション（`/app`）の内部実装（ライブラリ、ドメイン詳細）を除外した、プロダクトレベルの意思決定を記録しています。

## 決定項目一覧

| ID | 決定事項 | 概要 | ステータス |
| :--- | :--- | :--- | :--- |
| [ADR-101](./adr-101-product-experience-local-first-e2ee.md) | **ローカルファーストとE2EEによる絶対的プライバシーの保証** | ユーザーの手元でデータを暗号化・保持し、完全なプライバシーとオフライン動作を可能にするユーザー体験の決定。 | **Accepted** |
| [ADR-102](./adr-102-scraping-architecture-browser-extension.md) | **ブラウザ拡張機能を用いた分散型（ゼロインフラ）スクレイピング** | 金融機関の自動取得をユーザーのブラウザ拡張に委譲し、MFAの突破とサーバー運用コストのゼロ化、代理取得禁止の回避を両立する。 | **Accepted** |
| [ADR-103](./adr-103-synchronization-dumb-pipe.md) | **「愚かな土管（Dumb Pipe）」としての同期サーバーとセルフホスト** | 同期サーバーはビジネスロジックを持たず、暗号化データの仲介に特化。シングルバイナリで提供しセルフホストを容易にする。 | **Accepted** |
| [ADR-104](./adr-104-monorepo-resource-development-structure.md) | **モノレポ（Mono-Repository）構成による開発リソースの最適化** | クライアント、サーバー、プロトコル定義を単一リポジトリで管理し、仕様変更に強く少人数で開発しやすい体制を整備する。 | **Accepted** |

## システム全体のリソース・開発マッピング

本ADR群は、**hachimoku** が「プライベートで、安全で、低コストに運用できる」というコアバリューを提供するためのインフラ・組織設計の基盤となっています。
